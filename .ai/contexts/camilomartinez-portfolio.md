# Camilo Martinez Portfolio Context

## Product Summary

AI-driven fitness analytics platform with Next.js frontend and FastAPI backend.

## Vision

Deliver an end-to-end, production-grade analytics product that turns wearable data into actionable fitness insights.

## Operating Constraints

- Follow repository-native tooling and deployment conventions.
- Keep changes backward-compatible unless a migration is explicitly planned.
- Capture high-impact decisions in docs/specs before implementation.

## Core Commands

- Install: `pnpm install && cd backend && uv sync`
- Dev: `pnpm dev:all`
- Test: `pnpm test:db-schema`
- Lint: `pnpm exec next lint`
- Build: `pnpm build`
