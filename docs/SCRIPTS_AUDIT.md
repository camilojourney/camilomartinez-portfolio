## 🔗 **Detailed Script Connections**

### **1. Astoria Conquest Pipeline**

```
┌──────────────────────────────────────────────────────────────┐
│  STEP 1: Initial Setup (One-time)                             │
└──────────────────────────────────────────────────────────────┘
    ↓
    python scripts/one-off/generate_astoria_base_map.py
    ↓
    Creates:
      - backend/data/astoria-conquest/cache/astoria_graph.pkl
      - public/data/astoria-conquest/astoria-base-map.geojson

┌──────────────────────────────────────────────────────────────┐
│  STEP 2: Weekly Update (Automated via Celery)                │
└──────────────────────────────────────────────────────────────┘
    ↓
    Celery Task: update_astoria_progress_task()
    ↓
    Calls: python scripts/one-off/update_astoria_progress.py
    ↓
    Queries:
      - strava_runs (detailed_polyline)
      - activity_correlations
      - whoop_workouts (heart rate, strain)
    ↓
    Compares:
      - GPS tracks vs street network
      - Marks streets within 20m as "covered"
    ↓
    Enriches:
      - Adds WHOOP metrics (HR zones, strain)
    ↓
    Updates:
      - public/data/astoria-conquest/astoria-covered-streets.geojson
      - public/data/astoria-conquest/astoria-progress-stats.json

┌──────────────────────────────────────────────────────────────┐
│  STEP 3: Frontend Display                                     │
└──────────────────────────────────────────────────────────────┘
    ↓
    Next.js page: /projects/astoria
    ↓
    Loads GeoJSON files
    ↓
    Renders interactive map with:
      - Base streets (gray)
      - Covered streets (colored by recency)
      - Progress stats (% complete)
```

**Files Involved:**
- `scripts/one-off/generate_astoria_base_map.py` → Creates base map
- `scripts/one-off/update_astoria_progress.py` → Updates progress
- `backend/app/workers/tasks/astoria.py` → Schedules updates
- `public/data/astoria-conquest/*.geojson` → Data files
- `src/app/(main)/projects/astoria/page.tsx` → Frontend display

### **3. Database Setup Pipeline**

```
┌──────────────────────────────────────────────────────────────┐
│  INITIAL SETUP: Extensions & Schema                           │
└──────────────────────────────────────────────────────────────┘
    ↓
    node scripts/db/enable-vector-support.js
      → Installs pgvector extension (for AI embeddings)
    ↓
    node scripts/db/enable-postgis.js
      → Installs PostGIS extension (for geospatial)
    ↓
    cd backend && poetry run alembic upgrade head
      → Applies all Alembic migrations
    ↓
    psql $DATABASE_URL < scripts/db/setup-astoria-database.sql
      → Creates Astoria-specific tables

┌──────────────────────────────────────────────────────────────┐
│  VERIFICATION: Schema Checks                                   │
└──────────────────────────────────────────────────────────────┘
    ↓
    node scripts/db/check-vector-support.js
      → Confirms pgvector is working
    ↓
    node scripts/testing/check-database-schema.js
      → Validates all tables exist
    ↓
    node scripts/db/get-database-schema.js
      → Exports schema for documentation
```

**Files Involved:**
- `scripts/db/enable-vector-support.js` → pgvector setup
- `scripts/db/enable-postgis.js` → PostGIS setup
- `scripts/db/setup-astoria-database.sql` → Astoria tables
- `scripts/db/check-vector-support.js` → Verification
- `scripts/testing/check-database-schema.js` → Validation
- `backend/alembic/` → Main schema migrations
